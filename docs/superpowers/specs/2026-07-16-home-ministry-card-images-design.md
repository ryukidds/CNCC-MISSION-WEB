# 홈페이지 사역 카드 이미지 적용 디자인

## 목표

홈페이지의 `Our Ministries` 2×2 카드에 현재 회색 플레이스홀더 대신 제작된 16:9 보정 이미지를 표시한다.

## 범위

- 홈페이지 사역 카드 4곳만 변경한다.
- 사역 상세 페이지와 `src/data/cncc_db.json`은 변경하지 않는다.
- 기존 카드 링크, 제목, 설명, 애니메이션, 반응형 레이아웃은 유지한다.

## 이미지 매핑

| 카드 | 이미지 |
| --- | --- |
| 회복 및 예배 사역 | `/images/homeless-care-16x9-depth-v2.png` |
| 국내외 선교 활동 | `/images/global-mission-16x9-depth-v2.png` |
| 선교예배 | `/images/worship-community-16x9-depth-v2.png` |
| 선교사업 | `/images/business-as-mission-16x9-depth-v2.png` |

## 구현

`src/app/page.tsx`의 `ministryCards` 항목에 이미지 경로와 대체 텍스트를 추가한다. 기존 `.ministry-card-image` 플레이스홀더 요소는 실제 `<img>` 요소로 교체한다.

이미지는 기존 16:9 카드 영역을 유지하며 `width: 100%`, `aspect-ratio: 16 / 9`, `object-fit: cover`로 표시한다. 현재 둥근 모서리, 여백, 호버 이동 및 모바일 1열 배치는 그대로 유지한다.

## 접근성

각 이미지의 `alt`에는 현재 언어에 맞는 카드 제목을 사용한다. 이미지는 카드 내용을 보완하므로 빈 대체 텍스트로 처리하지 않는다.

## 검증

- 타입 검사 또는 프로젝트 빌드가 통과해야 한다.
- 네 카드가 지정된 이미지와 정확히 매핑되어야 한다.
- 데스크톱 2열과 모바일 1열에서 16:9 비율 및 크롭이 유지되어야 한다.
- 상세 페이지와 콘텐츠 JSON에 변경이 없어야 한다.
